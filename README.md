# chainbreaker-site

Public static site for the Chainbreaker Android app, served by GitHub Pages at https://mehharc.github.io/chainbreaker-site/.

- `index.html`: short landing page.
- `privacy.html`: the privacy policy linked from the Play listing. **Do not edit it here.** The source of truth lives in the app repository (`docs/privacy.html`); copy it over whenever it changes.

No scripts, no trackers, no build step.
